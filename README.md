# Face Mask Detection Using Deep Learning

## 📌 Project Overview

Face Mask Detection is a computer vision and deep learning project that detects whether a person is wearing a face mask or not. The system processes images or camera input and classifies detected faces into two categories: **With Mask** and **Without Mask**.

The project demonstrates how artificial intelligence (AI), deep learning, and OpenCV can be used for automated face mask detection. It can serve as a learning project for students and beginners interested in computer vision and AI applications.

## 🎯 Objectives

- Detect faces and identify whether a mask is present.
- Classify faces into With Mask and Without Mask categories.
- Apply deep learning techniques to a real-world computer vision problem.
- Explore image processing and automated classification using Python.
- Understand how AI-based detection systems can support safety-monitoring applications.

## ✨ Features

- Face mask classification.
- Detection of faces with and without masks.
- Image processing using OpenCV.

## ⚙️ How It Works

1. **Input:** The system receives an image or camera frame.
2. **Image Processing:** OpenCV processes the input image.
3. **Face Detection:** The system identifies faces using the configured detection model.
4. **Classification:** The detected face is classified as With Mask or Without Mask.
5. **Output:** The result is displayed to the user.
